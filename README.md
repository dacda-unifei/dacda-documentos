# dacda-documentos

Documentação, estatuto, planejamento, transparência e materiais institucionais do Diretório Acadêmico de Ciência de Dados Aplicada (DACDA) da UNIFEI.

## Apresentação

Este repositório público organiza as **minutas, modelos e documentos de trabalho** para estruturação institucional do DACDA. O objetivo é apoiar a representação estudantil com organização, continuidade entre gestões e transparência.

> **Importante:** este repositório não afirma formalização, registro ou reconhecimento já concluídos. Esses resultados são objetivos de etapas futuras.

## Objetivo do repositório

- centralizar documentos institucionais em versão editável;
- registrar planejamento, decisões e materiais de apoio;
- facilitar colaboração por issues e pull requests;
- fortalecer a transparência da atuação estudantil.

## Princípios de transparência

- linguagem clara e registro público do que for institucionalmente publicável;
- prestação de contas periódica e rastreável;
- proteção de dados pessoais e anonimização quando necessário;
- revisão colegiada de documentos sensíveis antes de divulgação.

## Como contribuir

1. abra uma issue com contexto e proposta;
2. desenvolva em branch própria;
3. abra pull request com resumo das alterações e pontos de revisão;
4. aguarde revisão antes de merge.

Consulte os detalhes em [CONTRIBUTING.md](CONTRIBUTING.md).

## Aviso jurídico e institucional

Os documentos de natureza jurídica deste repositório são **minutas/modelos de trabalho**. Antes de qualquer protocolo, registro ou uso oficial, o conteúdo deve ser revisado e validado pela UNIFEI e por profissional habilitado, com adequação às normas internas e à legislação brasileira vigente.
